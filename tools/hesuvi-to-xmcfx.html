Using the file in Head Tracking Host

  1. Put the converted WAVs in a folder of their own (unzip first if you saved a ZIP).
  2. X-MCFX install it and load the plugin X-MCFX-Convolver_8x2 in HTH, Input 7.1.
  3. In X-MCFX, choose the folder and pick a file. The channel count is stored in the file; if X-MCFX asks anyway, enter 8 (or 7 for the Reddit layout).
  4. Check with the speaker test of Windows (or Audio MIDI Setup on the Mac) that every channel comes from the right place. If not, reroute in HTH under Channels.

HeSuVi has no LFE filter of its own, so the LFE channel plays through the centre filter (bass cannot be localised). Head tracking is not possible with HeSuVi files.
